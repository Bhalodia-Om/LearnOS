What is this?

LeveretOS is a real operating system, written from nothing. No Windows, no Linux underneath , just code running directly on the hardware. Every file is commented for beginners, so the project doubles as a step-by-step guide to how an OS actually works, starting from the very first instruction that runs at boot.

Each lesson lives in its own folder and adds one new feature on top of the last. Reused code keeps its comments but gets no new ones , only new or changed code is freshly commented, so what's new each lesson stands out.

Lessons so far

  • 01Hello World
    Booting via GRUB and writing text straight to VGA memory
  • 02Text Output
    A moving cursor, putchar / print, newlines and wrapping
  • 03Text Input
    Reading the keyboard: scancodes, getchar, read_line
  • 04Print Numbers
    Turning integers into on-screen digits
  • 05String Helpers
    strlen, strcmp, memcpy, memset, and atoi

The goal

The long-term goal is to grow LeveretOS far enough to connect to the internet and pull down a simple web page over HTTP , building interrupts, memory management, and a network stack along the way. One lesson at a time.
